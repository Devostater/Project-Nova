# AI Context: Absolute Zero Interactive Reference Library

Use this library as the orientation and source-of-truth map for creative work involving AZI, Mind Space, Matrix, and the related Project Nova repository.

## Established identity and relationships
- **Absolute Zero Interactive (AZI)** is the parent studio. This is an owner-confirmed fact.
- **Mind Space** is an AZI game-development property. This is an owner-confirmed fact.
- **Matrix** is an AZI AI character, digital personality, and creative-media project. This is an owner-confirmed fact.
- **Project Nova** is the repository's current project: a 6DOF WebXR starfighter/space-flight simulator. Its relationship to Mind Space has not been confirmed. Do not treat them as synonyms or assume shared canon without owner confirmation.

## How to use this library
1. Start with [PROJECT_INDEX.md](PROJECT_INDEX.md) to choose the relevant project and references.
2. Read the project's established facts before writing. Repository observations are not automatically canon.
3. Keep established facts, observed implementation details, and proposed creative direction visibly distinct.
4. Do not invent names, backstory, plot, relationships, visual traits, voice, gameplay systems, brand marks, or music credits as established facts.
5. Where facts are missing, ask the owner or label the material as a proposal.

## Evidence labels
- **Established (owner-confirmed):** Explicitly confirmed by the owner.
- **Observed (repository):** Present in files, assets, metadata, or implementation; may describe a prototype rather than final canon.
- **Proposed:** Optional direction for future work. Never present as approved canon.
- **Open question:** Requires owner confirmation.

## Prompt-generation defaults
- Identify which property the prompt is for and its intended output (text, image, audio, UI, character, gameplay, or marketing).
- Use the appropriate project guide and preserve all established details.
- Treat proposed guidance as optional. Avoid filling unknowns with confident specifics.
- For images, specify subject, composition, environment, palette, lighting, materials, camera, and exclusions only when supported or clearly requested.
- For character work, preserve identity and personality; do not reduce Matrix to a generic assistant or invent a human biography.
- For game work, use the documented premise and mechanics; label new mechanics, factions, and lore as proposals.
- Ask a concise clarifying question when a missing decision would materially change the output.

## Scope and maintenance
This library currently records the studio/project relationships above and repository-backed Project Nova observations. Detailed Mind Space canon, Matrix biography/personality/appearance, and AZI visual identity have not been supplied in sufficient detail. Update the specific reference and this index when the owner confirms new facts.
