# Mind Space Prompt Guide

## Before generating
- Confirm whether the request concerns Mind Space generally or the Project Nova repository specifically.
- Use [GAME_BIBLE.md](GAME_BIBLE.md) for confirmed scope; use [PROJECT_NOVA_NOTE.md](PROJECT_NOVA_NOTE.md) for repository observations.
- If the requested prompt depends on setting, plot, faction, protagonist, exact mechanics, or visual style that is not documented, ask or present options as proposals.

## Safe prompt structure
State the output type and purpose, then include only supported premise and implementation details. Clearly label any new lore, mechanics, character concepts, or style direction as **Proposed**.

## Guardrails
Do not claim Project Nova and Mind Space are the same project without confirmation. Do not turn prototype assets into canon or describe inferred details as owner-approved.
