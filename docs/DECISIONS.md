## Focus rules
- About 90% of effort goes to shipping NOVA 1 and about 10% to the studio shell (name, logo, Meta publisher account, socials).
- Don't start a second game before launch. Side work is OK only if it's short, paid, and feeds Nova.
- Features beyond the V1 scope become **DLC candidates**: keep them, but don't let them block launch.
- Post-launch funding comes from Nova DLC 1. Game #2 starts only after DLC 1 ships.
